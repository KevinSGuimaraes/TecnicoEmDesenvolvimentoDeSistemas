# Desafio — Reproduza a página

Você recebeu o modelo visual de uma página sobre a **linguagem C**.

Sua tarefa é reproduzir a página utilizando **somente as tags HTML estudadas em aula**.

## Tags permitidas

```text
h1, h2, h3, h4, h5, h6, p, div, pre, blockquote, figure, figcaption, hr e img
```

## Regras

1. O nome **Linguagem C** deve ser o título principal.
2. Utilize títulos para organizar as diferentes partes da página.
3. Os textos explicativos devem utilizar parágrafos.
4. A imagem deve possuir um texto alternativo (`alt`).
5. Utilize uma figura para organizar a imagem e sua legenda.
6. Utilize uma separação horizontal entre as principais seções.
7. Organize as características da linguagem utilizando um container.
8. O código apresentado deve manter exatamente sua formatação original.
9. Utilize uma figura para organizar o código e sua legenda.
10. A frase apresentada como citação deve utilizar a tag apropriada.
11. **Não utilize CSS.**
12. **Não utilize tags que ainda não foram estudadas.**

## Objetivo

O objetivo não é apenas fazer a página funcionar.

Você deve observar o modelo apresentado e **escolher a tag HTML adequada para representar cada parte do conteúdo**.
