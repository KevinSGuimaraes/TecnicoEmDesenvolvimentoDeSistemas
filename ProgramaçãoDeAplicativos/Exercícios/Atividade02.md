# Atividade — Guia do Programador

## Desafio

Você deverá criar uma página HTML chamada **Guia do Programador**.

A página deverá apresentar informações para uma pessoa que está começando a estudar programação.

O objetivo da atividade é utilizar as tags HTML estudadas até o momento para **organizar corretamente diferentes tipos de informação**.

A atividade é **acumulativa**. Portanto, você poderá e deverá reutilizar todas as tags estudadas nas aulas anteriores.

---

## 1. Título

A página deverá possuir o título:

> **Guia do Programador**

Utilize uma das tags de título estudadas em aula.

---

## 2. Introdução

Crie um pequeno parágrafo explicando:

> O que é programação e por que aprender programação pode ser importante.

Utilize a tag de parágrafo estudada em aula.

---

## 3. Áreas da programação

Crie uma lista contendo pelo menos **5 áreas relacionadas à programação**.

Você poderá utilizar, por exemplo:

- Desenvolvimento Web
- Desenvolvimento de Jogos
- Aplicações Mobile
- Inteligência Artificial
- Sistemas Embarcados

Utilize as tags estudadas em aula que sejam adequadas para representar uma **lista não ordenada**.

---

## 4. Etapas para aprender programação

Crie uma lista apresentando pelo menos **5 etapas** que você considera importantes para uma pessoa que está começando a programar.

Exemplo:

1. Aprender lógica
2. Conhecer uma linguagem
3. Criar pequenos programas
4. Estudar banco de dados
5. Desenvolver projetos

Utilize as tags estudadas em aula que sejam adequadas para representar uma **lista ordenada**.

---

## 5. Conceitos importantes

Crie uma lista contendo pelo menos **5 conceitos relacionados à programação**.

Cada conceito deverá possuir:

- um **termo**;
- uma **definição**.

Exemplo:

**Algoritmo**  
Conjunto de passos utilizados para resolver um problema.

**Variável**  
Espaço utilizado para armazenar um valor.

**Programa**  
Conjunto de instruções executadas pelo computador.

**Banco de dados**  
Sistema utilizado para armazenar e organizar informações.

**Código-fonte**  
Conjunto de instruções escritas pelo programador.

Organize corretamente os **termos e suas respectivas definições** utilizando as tags estudadas em aula.

---

## 6. Comandos

Crie uma seção chamada:

> **Comandos que todo programador deveria conhecer**

Apresente pelo menos **5 comandos** relacionados à programação ou ao computador.

Exemplo:

- `git add`
- `git commit`
- `git push`
- `git pull`
- `git status`

Utilize as tags estudadas em aula que sejam adequadas para representar um **conjunto de comandos**.

---

## 7. Exemplo de código

Crie uma pequena representação de código utilizando uma das tags estudadas anteriormente.

Exemplo:

```text
algoritmo
    receber nome
    mostrar nome
```

O conteúdo deve aparecer preservando sua organização original.

---

## 8. Frase sobre programação

Inclua uma frase relacionada à programação.

Exemplo:

> Programar é transformar uma ideia em instruções que um computador consegue executar.

Utilize uma das tags estudadas anteriormente que seja adequada para representar uma **citação**.

---

## 9. Organização da página

Organize as diferentes partes da página utilizando as tags de estrutura estudadas anteriormente.

A página deverá possuir:

- Título
- Introdução
- Áreas da programação
- Etapas para aprender programação
- Conceitos importantes
- Comandos
- Exemplo de código
- Frase sobre programação

---

# Regras

1. A atividade deverá ser desenvolvida **somente com HTML**.
2. **Não utilize CSS.**
3. **Não utilize JavaScript.**
4. Não utilize tags que ainda não foram apresentadas em aula.
5. Utilize as tags aprendidas nas aulas anteriores.
6. Utilize obrigatoriamente as novas tags apresentadas nesta aula.
7. O conteúdo deverá ser organizado de acordo com a finalidade de cada tag.
8. Não copie a estrutura pronta de páginas encontradas na internet.
9. O conteúdo apresentado nos exemplos pode ser utilizado como referência, mas você deverá produzir seu próprio conteúdo.
10. A página deverá ser organizada de maneira clara e coerente.

## Desafio extra

Depois de finalizar a página, revise todo o código e tente responder:

> **Por que você escolheu cada tipo de lista para cada informação apresentada?**

A escolha da tag deve estar relacionada ao **significado do conteúdo**, e não apenas à aparência que ela apresenta no navegador.
